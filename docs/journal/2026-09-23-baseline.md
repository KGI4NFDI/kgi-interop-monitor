Nine records are held at A* only by their registry record: GovData, dblp,
FactGrid (twice), MaRDI, ORKG, Semantic Kompakkt (twice) and Wikidata. Their
endpoints clear all three layers. Correcting eleven `dcat:endpointURL` values
is the largest improvement available, it is entirely in KGI's own hands, and
the monitor will show it the day it lands. That is the case for starting the
remediation phase with the registry, not with the partners.

## Differences from the checklist that are not improvements or regressions

- Record counts differ by one because the July census keyed records by title
  and merged the two "Semantic Kompakkt" records.
- A3 and A4 move between each other when a server goes down: a dead URL is
  A4, and A3 is then "not measured". GESIS KG and TweetsCov19 were
  answering in July and are down today.
- B3 cannot reproduce the Wikidata observation on a schedule by design
  (ADR 0004). It needs `--heavy`.

## Second run, from GitHub Actions

Run `2026-09-23T0120Z` (workflow dispatch, vantage `github-actions/linux`,
491 seconds against 186 locally) agreed with the local baseline on every
grade. Two records differed in single checks:

- ClaimsKG's B3 warning (COUNT(DISTINCT) eleven times slower) did not recur;
  the ratio sits near the threshold.
- TweetsKB answered layer C locally and returned 502 to every layer C query
  from GitHub, as it had in the earlier local run. It flaps; the history is
  the right instrument for it, not a single run.

Latency did not agree: median 109 ms from the development machine in
Germany, 416 ms from the GitHub runner, and Nomisma, which is US-hosted, got
faster (397 to 269 ms). Latency is therefore only compared within one
vantage point (`0eca20d`), and every scheduled run from now on comes from
the same one.

The run also warned that the pinned actions target the deprecated Node.js 20
runtime; they are at v7 now.

## Third run

Run `2026-09-23T0131Z` (GitHub Actions, on the v7 actions, 190 seconds):
TweetsKB answered nothing at all (HTTP 502 Proxy Error in every request
form) and fell from grade A to none. Over three runs it has answered fully,
answered layers A and B but not C, and not answered. Everything else held its
grade. This is the flapping the KPI draft (K5) warned about, and the reason
the page shows "answered" as a share of runs rather than as a yes or no.
